## Usage guidelines

- **One block of thinking** — Reasoning discloses a single block of reasoning text. When reasoning interleaves with tool calls, [Steps](/primitives/steps) shows them in order.
- **The parts ship no copy and no markdown** — `Reasoning.Trigger` has no label, and `Reasoning.Content` renders its children as given. A label that changes while the model thinks, sections and markdown are yours, built from `useReasoning` and your own text.
- **A stored message needs its duration passed in** — the root only times a stream it watches. A message loaded from history never streamed in this mount, so pass the saved seconds through `duration`, or `useReasoning().duration` stays `undefined`.
- **Get started** — see [Quick start](/quick-start) to add the package.

## Anatomy

```tsx
<Reasoning.Root>
  <Reasoning.Trigger />
  <Reasoning.Content />
</Reasoning.Root>
```

A realistic block. `ThinkingLabel` is your component that reads `useReasoning`,
and `Markdown` is your renderer, because the package ships neither:

```tsx
<Reasoning.Root isStreaming={isStreaming} duration={savedDuration}>
  <Reasoning.Trigger>
    <ThinkingLabel />
  </Reasoning.Trigger>
  <Reasoning.Content>
    <Markdown>{reasoningText}</Markdown>
  </Reasoning.Content>
</Reasoning.Root>
```

## Examples

### Labelling the trigger while it streams

Pass `isStreaming`, and read the rest from `useReasoning`. While it is true, the
root carries `data-streaming` and `aria-busy`. When it turns false, the root
stores the elapsed seconds as `duration`, so the label below moves from
"Thinking…" to "Thought for 3s" without timing anything itself.

## API reference

Every part accepts `className`, `style`, and `render` (see
[Styling](/handbook/styling)) and emits a bespoke part attribute (`data-<part>`) unless noted.

### Reasoning.Root

The disclosure root. Tracks how long `isStreaming` stayed true and hands the
elapsed seconds back through `useReasoning`, so a label can change without the
consumer timing anything. Renders a `<div>` element.

export const rootProps = [
  { name: "isStreaming", type: "boolean", default: "false", description: "Whether the reasoning is still streaming. The root starts timing when it turns true, and stores the elapsed seconds as duration when it turns false." },
  { name: "duration", type: "number", description: "Seeds useReasoning().duration, in seconds, for reasoning that finished before this mount. The root reads it once on mount and ignores later changes. The next stream it watches replaces the value." },
  { name: "defaultOpen", type: "boolean", default: "false", description: "Uncontrolled initial open state." },
  { name: "open", type: "boolean", description: "Controlled open state." },
  { name: "onOpenChange", type: "(open: boolean) => void", description: "Fires on toggle." },
];

### Reasoning.Content

The collapsible panel. Publishes its measured height while a transition runs
and releases it once settled open, so a panel that is open keeps growing as text
streams in. Renders a `<div>` element.
